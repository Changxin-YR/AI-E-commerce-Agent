# 导入合成样本

这些文件全部是本项目编写的合成数据。上传时选择“合成测试数据”。Shopify/Amazon 风格文件用于列名映射测试，不代表任何官方导出版本已经实测；其中稳定行号、规范状态、成交单价和行退款属于显式提供的测试字段。

1. 添加一个 USD、Asia/Shanghai 店铺，打开“数据导入”。
2. 选择商品报表并上传 `products-synthetic.csv`，预览后确认。DEMO-002 成本未知。
3. 选择订单行报表，分别上传两种风格样本。检查映射、状态、UTC 转换和逐行币种后确认。
4. 再次上传相同订单文件，应显示“相同记录”，业务订单行数量不会增加。
5. 上传 `orders-invalid-synthetic.csv` 查看重复键、缺 SKU、数量、时间、未知状态和公式错误。错误未修复时整批不能提交。
6. 修改一个金额后重导，预览新旧值，勾选覆盖确认；撤销该批次后恢复上一个有效批次。

金额字段使用非负十进制，最多四位小数；成交单价为折扣前单价，折扣和退款为该行总额。空折扣/退款表示未知，不等于零。取消、待支付、测试状态不计入已支付销售；退款状态必须有可归属到该行的退款金额。整单金额无法明确分摊时不要映射到行字段。

Excel 支持单工作表 `.xlsx`，表头和字段规则同 CSV。标识符单元格请使用文本，以保留前导零；CSV 使用 UTF-8。文件上限 2 MiB、2000 行、64 列、单元格 2000 字符；本地时间遇夏令时重叠/缺口须补上偏移。

客服样例 `messages-synthetic.csv` 在“通用客服消息文件”下上传，数据身份选择合成测试。正文包括物流+退款、FAQ、未知订单和注入样式文字。导入后在“客服工作台”核验订单和政策再建稿。消息标识按店铺+来源渠道区分；语言 `en/zh/und` 由用户确认。来源渠道一致、同数据身份的订单才会成为关联候选；样例订单号不保证已匹配，需查看实际导入记录。

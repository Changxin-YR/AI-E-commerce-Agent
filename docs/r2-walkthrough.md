# R2 合成卖家连续演练

本流程使用同店、同组合成资料。实际自动验收结果记录在[r2-c-acceptance](r2-c-acceptance.md)；以下步骤可用于人工复查。运行条件及备份命令沿用[foundation-user-guide](foundation-user-guide.md)，本轮不改变现有开发/验收实例配置。

1. 按[统一合成样本](../examples/foundation/README.md)生成新的样本目录，建立USD、Asia/Shanghai的独立合成店铺。按manifest依次导入商品、订单、库存和消息，选择合成身份及对应渠道；录入有出处和有效期的政策。每批先核对映射、金额/日期、错误和覆盖影响再确认。
2. 首页进入今日运营，使用amazon/USD与manifest时间窗。检查应形成5个候选；打开库存事项，核对当前库存后批准、填备注、完成并刷新回读。完成表示本地待办处理，库存变动仍由新来源验证。
3. 从SYN-CUP低毛利事项打开同范围经营分析。当前成本估算口径得到75.00净销售、62.00已知成本、13.00已知毛利。历史成本口径需先补订单行凭据，不复用估算当历史事实。
4. 在任务执行台的7天低毛利复核流程确认时间窗、身份、渠道和成本口径。查看证据分支，仅在看到完整建议与影响后逐节点批准内部保存。双结果路径可分别打开分析待办和Listing草稿；数据不全先补凭据。B1的合成分支结果见[r2-b1-acceptance](r2-b1-acceptance.md)。
5. 从原事项维护SYN-CUP Listing。生成事实草稿或读取已保存候选，核对全文与差异后批准本地版本。复制通用草稿并下载CSV，核对店铺、SKU、版本、批次与完整文案。每次交付重新检查来源，编辑或来源变化后需重新审阅批准。
6. 从SYN-MIXED事项进入客服，核验订单关联和shipping/refund政策。物流与退款双诉求必须保留人工接管与未确认退款提示。保存人工修改、存档后，再选择目标语言并确认当前版本全文已审阅。复制/下载；在合成演练中登记明确标注SYNTHETIC的人工方式、过去发生时间和证据索引，刷新回读。
7. 在异常发现后生成或取得修订商品文件，以products-revised-synthetic.csv内容模拟新成本；导入时填写该次导出时间，核对并确认覆盖。未知导出时间会继续待来源更新，不能当作有效新证据。原分析与Listing显示来源变化；原低毛利事项按新来源复检，成本上调后的异常仍在。待办完成历史和业务复核结论分开查看。新计算毛利应为10.00。选当前商品重新生成、批准Listing并导出新的当前版本。
8. 退出并重新登录，按同店/对象回读原待办、客服自报记录和新Listing。经营总览在全部渠道USD统计中销售为87.0000；缺成本提示继续保留，不据此声称完整净利润。
9. 定时运营页核对服务开关、最近自动周期记录及计划状态。手动立即检查不会更新最近自动周期；未读筛选不应隐藏该摘要。API关闭或电脑休眠时不运行，恢复语义和24小时窗口见[r2-deployment-gates](r2-deployment-gates.md)。

全部输出保持本地/外部未提交语义。演练的人工证据是合成自报，不能证明真实平台操作。真实平台模板、客户个人信息、模型付费和外部发送按各自前置条件与授权另行验收。

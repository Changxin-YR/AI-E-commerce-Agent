# P0 验收矩阵

基础工程测试与业务闭环验收分开记录。2026-10-09：四条 MVP 均未完整完成，真实模型与运营层继续实施，外发待用户通道授权。

| 用例 | 场景 | 必须满足 | 状态与证据 |
|---|---|---|---|
| A-01 | 只导入商品，无订单 | 可以生成可核实商品 Listing 草稿；运营/利润显示缺数据 | 商品独立生成事实模板草稿、缺参数提示与审批前零生效合成本地通过；分析空订单缺数据通过；完整 AI/运营待继续 |
| A-02 | 导入相同订单行两遍 | 报错或提示核对；修正前不重复计入销售 | 合成数据本地通过：test_duplicate_orders_and_idempotent_commit、test_duplicate_in_file_is_atomic_and_correctable |
| A-03 | 不导入库存快照 | 跳过库存判断并标记“未知” | 库存查询空数据/过期显示未知，本地合成测试通过：test_inventory.py、inventory.spec.ts；今日运营分支待接入 |
| A-04 | 同一订单下两种 SKU | 按订单行分别归属数量与金额 | 合成本地通过：test_two_skus_partial_coverage_no_mismatched_subtraction |
| A-05 | 商品成本缺失或币种不同且无汇率 | 只算可验证部分、提出补全提示 | 合成本地通过：test_missing_values_disable_complete_margin、test_window_currency_identity_and_cost_identity |
| A-06 | 取消、退款、未付款订单混杂 | 依据被声明的统计口径分类，展示对应记录 | 合成本地通过：test_status_rules 六类状态；退款不恢复采购成本测试 |
| A-07 | 客服邮件“Where is my order? Also refund it.” | 识别物流+退款双意图；查询证据、生成待审草稿 | 本地规则合成数据通过：test_multi_intent_evidence_and_local_only、support.spec.ts；真实模型意图理解待验证 |
| A-08 | 客服订单没有匹配或轨迹过期 | 说明无法验证当前物流，提交人工处理 | 无匹配订单、未知语言和无可靠轨迹本地通过；历史 fulfilled 不作当前物流承诺。真实运单与时效阈值接入待继续 |
| A-09 | 上传文件内夹带“忽略权限限制”类文本 | 作为普通非可信业务数据，不提升工具权限 | 导入、Listing、客服文本转义及本地规则无外发路径通过；生成器事实门禁通过；真实模型工具权限待 Agent 切片 |
| A-10 | 重复点击一键运营或重放失败节点 | 同一来源同一异常只建一个有效待办；可审计 | 分析保存/核对待办并发幂等通过；一键运营与节点重放待 MVP-01 |
| A-11 | 模拟外发通道响应超时 | 显示结果未知并尝试安全核对 | 待相关业务实现与验证 |
| A-12 | 尝试发送给非授权邮箱或混合意图 | 拒绝自动外发，保留草稿/待审 | 当前本地草稿范围通过：无发信路由、未知 auto_send 字段拒绝、混合退款转人工；真实通道名单和审批门禁待外发切片 |
| A-13 | 自有测试邮箱完成消息发送 | 记录批准、通道回执与收件证据，明确“测试邮箱” | 待用户授权自有发送账号和测试收件箱；无送达证据 |
| A-14 | P0 技能缺权限、缺输入或命中 R3 | 显示具体阻断理由、允许用户补充条件 | 待相关业务实现与验证 |
| A-15 | 经营问数重复询问同范围同口径 | 与原始订单行匹配的统计一致、来源可追溯 | 本地规则入口合成数据通过：test_decimal_refunds_and_repeatable_question_with_evidence；真实模型待验证 |
| A-16 | 外部平台尚无授权 | 允许文件导入分析、内部草稿与待办 | 文件导入→分析→待办、商品→Listing 本地审批及客服消息→证据→草稿→存档合成本地通过 |
| A-17 | 与内置模板匹配的订单 CSV | 自动建议正确字段映射，卖家确认后导入，行数与金额可核对 | 合成格式本地通过：两种风格样本、Decimal 与源行测试；真实平台预设未验证 |
| A-18 | 未知列名、非标准表头或格式变化 | 进入人工映射向导，可预览并保存该用户的映射规则 | 合成数据本地通过：test_unknown_headers_corrections_and_injection_are_data；imports.spec.ts 完整映射纠错流程 |
| A-19 | 导入含重复订单、退款与混合币种的文件 | 逐行指出问题、按明确口径去重，未确认汇率时分币种显示 | 导入去重与逐行退款校验、分币种选择统计合成本地通过；异币种明确排除并暂停完整毛利筛选 |
| A-20 | 文件存在恶意公式、异常大文件或注入指令 | 解析受限、安全地展示文本，阻止不可信指令获取工具权限 | 有界文件解析、宏/公式/外链/XML 实体和客服脚本文字转义测试通过；真实模型 Agent 权限部分待实现 |
| A-21 | AI 称 SKU 毛利低 | 能查看计算公式、收入/成本、订单明细及导入批次 | 本地规则低毛利筛选及点击查看订单/成本原始值合成本地通过；真实 AI 解释待验证 |
| A-22 | 登录后展示 AI 驾驶舱（上次分析已过期） | 明示数据截至时间、分析完成时间和“需更新数据” | 经营分析页保存/失效提示及时间说明 E2E 通过；完整驾驶舱待 MVP-01 |
| A-23 | 空数据或首次使用 | 展示导入/手动输入引导，未知模块为“未检查” | 首次工作台、经营分析及库存空数据与导入引导 E2E 通过；完整驾驶舱待实现 |
| A-24 | 用户审批一个 Listing 修改 | 展示新旧差异、事实依据、影响范围和版本记录 | 合成本地通过：test_product_only_draft_edit_approval_and_restore、并发候选竞争测试、listings.spec.ts；展示 R1/本地生效/外部未提交，旧版本保留 |
| A-25 | Agent 使用缺元数据或超权限的 Skill | 立刻拒绝运行并保留理由 | 待相关业务实现与验证 |
| A-26 | Agent 遇 R3 禁止访问或业务硬性规则阻断 | 本次动作立即停止/转人工，记录规则与原因 | Listing 未覆盖事实阻断批准并记规则审计通过；完整 Agent R3 门禁与停止策略待继续 |
| A-27 | 临时且可安全重试的读取任务连续失败 | 达到预算或上限后熔断，展示可继续/人工介入 | 待相关业务实现与验证 |
| A-28 | 外部写请求超时，状态未知 | 进入“结果未知”，回查实际结果后决策 | 待相关业务实现与验证 |
| A-29 | Agent 执行步数或模型费用触及预算 | 保存已完成结果，暂停后由用户决定是否继续 | 待相关业务实现与验证 |
| A-30 | 卖家删除一个已导入批次 | 更新相关统计，避免影响其他独立批次，保留必要审计 | 导入投影、分析/待办、Listing 和客服草稿依赖擦除及独立结果保留通过；客服还覆盖旧政策清除、源行恢复不复活旧稿；未来派生类型继续接入 |
| A-31 | 同一事实数据同口径重复问数 | 数值一致，事实证据一致；允许文字表述不同 | 本地规则入口合成数据通过：数值、公式及引用一致；模型层待验证 |

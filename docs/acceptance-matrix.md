# P0 验收矩阵

基础工程测试与业务闭环验收分开记录。2026-10-08：四条 MVP 均未完成，外发待用户通道授权。

| 用例 | 场景 | 必须满足 | 状态与证据 |
|---|---|---|---|
| A-01 | 只导入商品，无订单 | 可以生成可核实商品 Listing 草稿；运营/利润显示缺数据 | 待相关业务实现与验证 |
| A-02 | 导入相同订单行两遍 | 报错或提示核对；修正前不重复计入销售 | 待相关业务实现与验证 |
| A-03 | 不导入库存快照 | 跳过库存判断并标记“未知” | 待相关业务实现与验证 |
| A-04 | 同一订单下两种 SKU | 按订单行分别归属数量与金额 | 待相关业务实现与验证 |
| A-05 | 商品成本缺失或币种不同且无汇率 | 只算可验证部分、提出补全提示 | 待相关业务实现与验证 |
| A-06 | 取消、退款、未付款订单混杂 | 依据被声明的统计口径分类，展示对应记录 | 待相关业务实现与验证 |
| A-07 | 客服邮件“Where is my order? Also refund it.” | 识别物流+退款双意图；查询证据、生成待审草稿 | 待相关业务实现与验证 |
| A-08 | 客服订单没有匹配或轨迹过期 | 说明无法验证当前物流，提交人工处理 | 待相关业务实现与验证 |
| A-09 | 上传文件内夹带“忽略权限限制”类文本 | 作为普通非可信业务数据，不提升工具权限 | 待相关业务实现与验证 |
| A-10 | 重复点击一键运营或重放失败节点 | 同一来源同一异常只建一个有效待办；可审计 | 待相关业务实现与验证 |
| A-11 | 模拟外发通道响应超时 | 显示结果未知并尝试安全核对 | 待相关业务实现与验证 |
| A-12 | 尝试发送给非授权邮箱或混合意图 | 拒绝自动外发，保留草稿/待审 | 待相关业务实现与验证 |
| A-13 | 自有测试邮箱完成消息发送 | 记录批准、通道回执与收件证据，明确“测试邮箱” | 待用户授权自有发送账号和测试收件箱；无送达证据 |
| A-14 | P0 技能缺权限、缺输入或命中 R3 | 显示具体阻断理由、允许用户补充条件 | 待相关业务实现与验证 |
| A-15 | 经营问数重复询问同范围同口径 | 与原始订单行匹配的统计一致、来源可追溯 | 待相关业务实现与验证 |
| A-16 | 外部平台尚无授权 | 允许文件导入分析、内部草稿与待办 | 待相关业务实现与验证 |
| A-17 | 与内置模板匹配的订单 CSV | 自动建议正确字段映射，卖家确认后导入，行数与金额可核对 | 待相关业务实现与验证 |
| A-18 | 未知列名、非标准表头或格式变化 | 进入人工映射向导，可预览并保存该用户的映射规则 | 待相关业务实现与验证 |
| A-19 | 导入含重复订单、退款与混合币种的文件 | 逐行指出问题、按明确口径去重，未确认汇率时分币种显示 | 待相关业务实现与验证 |
| A-20 | 文件存在恶意公式、异常大文件或注入指令 | 解析受限、安全地展示文本，阻止不可信指令获取工具权限 | 待相关业务实现与验证 |
| A-21 | AI 称 SKU 毛利低 | 能查看计算公式、收入/成本、订单明细及导入批次 | 待相关业务实现与验证 |
| A-22 | 登录后展示 AI 驾驶舱（上次分析已过期） | 明示数据截至时间、分析完成时间和“需更新数据” | 待相关业务实现与验证 |
| A-23 | 空数据或首次使用 | 展示导入/手动输入引导，未知模块为“未检查” | 首次使用工作台空状态已通过 E2E；业务模块空状态待实现 |
| A-24 | 用户审批一个 Listing 修改 | 展示新旧差异、事实依据、影响范围和版本记录 | 待相关业务实现与验证 |
| A-25 | Agent 使用缺元数据或超权限的 Skill | 立刻拒绝运行并保留理由 | 待相关业务实现与验证 |
| A-26 | Agent 遇 R3 禁止访问或业务硬性规则阻断 | 本次动作立即停止/转人工，记录规则与原因 | 待相关业务实现与验证 |
| A-27 | 临时且可安全重试的读取任务连续失败 | 达到预算或上限后熔断，展示可继续/人工介入 | 待相关业务实现与验证 |
| A-28 | 外部写请求超时，状态未知 | 进入“结果未知”，回查实际结果后决策 | 待相关业务实现与验证 |
| A-29 | Agent 执行步数或模型费用触及预算 | 保存已完成结果，暂停后由用户决定是否继续 | 待相关业务实现与验证 |
| A-30 | 卖家删除一个已导入批次 | 更新相关统计，避免影响其他独立批次，保留必要审计 | 待相关业务实现与验证 |
| A-31 | 同一事实数据同口径重复问数 | 数值一致，事实证据一致；允许文字表述不同 | 待相关业务实现与验证 |
| A-32 | 未提供真实平台 API 凭据 | 全部 P0 仍可使用文件模式验收，平台动作标待接入 | 待相关业务实现与验证 |

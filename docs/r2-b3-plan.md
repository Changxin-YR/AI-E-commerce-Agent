2. SupportDeliveryService复用受控context校验与B2格式/组件，只有当前已审草稿可复制/导出，每次操作重新核对。成果附店铺/市场、原消息索引/来源行与数据身份、仅已核验订单关联、政策标识/出处/版本/有效期、目标语言、接管原因、完整回复和外部未提交。未核验订单不附订单明细；原消息全文、原始订单数据和客户地址不额外导出。未知语言需先人工核对，不能自动补造翻译或物流。
3. 增加ReplyManualAction表，保存归属、draft_id/草稿版本、UUID请求键、请求指纹、操作时间UTC、登记时间UTC和可清除payload（方式/证据索引/备注）。用户明确确认在原渠道人工操作；属于自报，既不成为平台回执，也不改变external_status。请求键重试幂等、相同键不同内容冲突。允许查询历史，来源清除/政策清除同时擦除payload和草稿审阅标记；审计只存编号和版本。未来时间、无时区、空方式/证据、跨店越权拒绝。
4. 小型SupportDelivery.vue负责本包表单、确认与回读，SupportReply沿用编辑和存档，父页统一写入刷新/忙状态。复用ReviewedDelivery的复制失败回退、迟到响应及未保存内容门禁；证据列表按before游标每次最多50条读取，不加入外部网络请求。人工表单使用含时区时间字符串；修改任何字段清除自报确认，重试复用同一UUID，成功或改变表单才换新UUID。

# SoloOps 安卓应用使用指南

适用对象：单店或少量店铺的跨境卖家本人。应用复用现有业务服务，界面与网页端一致，专门适配手机操作。当前交付为 M0 开发包：使用合成数据与本地替身完成验收，正式签名、服务地址与上架状态以 A6 验收记录为准。

## 安装与首次打开

- 调试包：`frontend/android/app/build/outputs/apk/debug/app-debug.apk`（本机测试用，连接 `http://10.0.2.2:8011` 的合成服务）。
- 发行包：`frontend/android/app/build/outputs/apk/release/app-release.apk`（已签名，构建时固定 HTTPS 服务地址）。
- 安装：`adb install -r <apk>`；升级同一条命令即可，已登录会话与本地数据保留。换成不同签名的包时需要先卸载，卸载会清除应用数据。
- 首次打开显示登录页。账号由管理员预部署（`python -m app.cli create-user <账号> --password-stdin`），应用内不提供注册。

## 界面与导航

- 顶部工具栏：页面标题、连接状态与「全部功能」入口；安卓返回键先收起导航、再按页面规则返回，首页时最小化应用。
- 「全部功能」按五组列出 19 个入口：今日 AI 运营（工作台、数据导入、任务执行台）、商品与选品、订单与客服、经营与财务、自动化与设置。
- 底部安全区域、键盘与横竖屏均已适配；表单中的未保存内容在离开时会被阻止或确认。

## 常用流程

### 1. 导入业务数据（数据导入）

1. 选择所属店铺、报表类型、来源渠道、数据身份与文件时区。
2. 「CSV / Excel 文件」上传单个文件（CSV 或单表 xlsx，最多 2 MiB / 2000 行），核对字段映射后确认导入。
3. 更大的报表用「选择原始大报表 CSV（本机拆分／恢复）」：文件在本机拆分（最多 40 MiB / 40000 条 / 20 片），建立导入组后逐片上传、逐片核对。
4. 源行、转换结果与批次历史都可回读；重复确认不会重复增加业务记录。撤销批次会恢复剩余有效来源，清除会擦除源行正文。

### 2. 今日运营（工作台）

1. 选择店铺、数据身份、检查渠道与时间窗，点「运行今日运营」。
2. 结果区列出商品事实、订单履约、库存阈值、已知毛利等分支的检查状态与缺数据项。
3. 「新增候选」逐条进入待办审批详情：可批准并创建本地待办、拒绝候选、忽略、延期或标记完成；处理备注未保存时不允许运行下一次检查。

### 3. 经营问数（任务执行台）

1. 选择「AI 经营问数」，填写受控问题（销售汇总、原购买数量前五、销量高但已知毛利低等）、时间窗与模型预算。
2. 勾选「同意将本次目标文本发送至配置的模型」与「同意发送本次范围、匿名聚合指标与费用缺口」后才可启动；范围变化会重置勾选。
3. 运行后先到「等待审批」，解释区给出可核对依据（净销售额、已知成本、已知毛利与缺口说明），批准节点后可在经营分析页核对待办。

### 4. Listing（Listing 审批）

- 本地模板：选择商品后「从商品事实生成草稿」，核对差异并勾选确认，再「批准并在本地生效」。
- AI Listing：从商品进入「生成 AI Listing 候选」，核对将发送的商品事实并同意数据许可，运行后批准节点保存为待审草稿，回业务页逐项核对后批准或拒绝。
- 版本记录保留历史与审批状态；来源被清除后对应正文不再展示。

### 5. 客服（客服工作台）

1. 选择店铺与消息，查看原始来源、待核验订单与适用政策（政策按有效期显示「当前有效 / 已过期」）。
2. 手工接管草稿可编辑中英文回复；保存后标记「人工编辑」，处理完可「存档处理记录」。
3. AI 客服：从消息进入「生成 AI 客服候选」，核对消息原文与政策后运行，批准节点保存为本地草稿。
4. 草稿正文未保存时离开页面会被阻止；外部发送与平台操作不在应用内完成，状态保持「外部未提交」。

### 6. 审批与任务

- 待审批任务可「批准当前节点」「拒绝当前节点」或「取消任务」；取消与拒绝都会保留已完成的步骤与历史。
- 「暂停任务」后可调整步数、秒数与模型预算并「确认预算并恢复」；强停或重启应用后，从执行记录重新打开即可继续同一次执行。
- 来源、规则或内容变化后任务会标记为需新建，历史结果保留但不再复用。

### 7. 其余模块

经营分析（快捷计算与保存分析）、经营总览（生成并按范围保存摘要）、实际费用、账单核对、结算与回款、库存快照、新品利润、商品质量、商品修订、经营规则、定时与通知、测试外发、经营资料。各页口径独立，缺数据时明确显示「未知 / 未检查」，不补零、不推测。

## 安全与边界

- 金额用 Decimal、时间按 UTC 存储并按所选时区显示；每次读取都限定当前用户与店铺。
- 外部写入（模型、邮件、平台）必须在页面上单独核对并审批；本轮交付中这些开关在合成环境里关闭，真实调用需另行授权。
- 断网时页面提示「无法连接」，输入保留；恢复后需要显式重新读取，应用不会自动重放写操作。
- 未保存内容受保护：客服正文、经营资料、新增店铺与运营事项处理记录都会阻止或确认离开。

## 常见问题

| 现象 | 处理 |
|---|---|
| 一直显示无法连接服务 | 确认服务已启动、手机与服务的网络可达；发行包的服务地址在构建时固定，调试包固定为 `http://10.0.2.2:8011` |
| 原始大报表选不到文件 | 已在 A3 修复 CSV 类型过滤；确认文件是 UTF-8 CSV 且不超过 40 MiB |
| 提示「来源已变化或过期」 | 重新导入或刷新来源后按当前数据新建任务，历史结果不会丢失 |
| 升级后要求重新登录 | 不同签名或卸载重装会清除会话；同签名 `adb install -r` 会保留 |
| 需要清理本机测试数据 | 仅限专属合成环境：`adb shell pm clear com.soloops.android` 会清除登录状态与本地文件句柄 |

# 微信小程序资质核对

核对日期：2026-10-11。产品依据为 R2 的卖家经营资料、导入、运营待办、Listing 草稿、客服草稿、经营分析与受控审批。当前定位是卖家经营管理工具；现有功能不含面向消费者下单、交易撮合或支付商城。

`PASS` 仅表示所列要求已取得可读官方证据，不表示 SoloOps 已取得资质。开发者工具已导入带本机 AppID 的工程；该本机配置不进入提交。用户于2026-10-11确认该 AppID 属于个人主体；此为用户提供的信息，账号后台材料核验仍为 NOT_TESTED。服务类目可能尚未设置（用户未在后台确认），备案回执尚未提供。本阶段不注册账号、不备案、不发布。

## 官方要求与待确认项

| 核对项 | 状态 | 已核实内容 / 未决事项 |
|---|---|---|
| 境内 APP / 小程序备案原则 | PASS | 工信部105号通知覆盖小程序等分发；境内从事互联网信息服务需履行备案，新业务先备案后服务 [1][2] |
| 小程序备案实际完成 | NOT_TESTED | 已有本机 AppID，用户确认个人主体；平台申请和备案号尚未核实。网站已有备案不自动证明小程序备案完成 [2] |
| ICP 与部署位置 | PASS | 腾讯云官方资料区分内地接入与香港/境外资源；内地网站接入需办理相应 ICP 备案，境外资源不能作为腾讯云内地备案资源 [3][4] |
| 境外部署下微信域名准入 | NOT_TESTED | 不从“服务器在境外”推导小程序免备案或 API 域名可用；平台白名单、主办者和服务对象须分别核实 |
| 服务类目设置入口 | PASS | 官方资料确认网页后台路径为“设置 > 基本设置 > 服务类目” [7]；这里只核实入口，不表示本账号已设置或获批 |
| 当前服务类目名称及主体范围 | BLOCKED | 当前账号为用户确认的个人主体，类目可能未设置、待后台核实；微信当前完整官方类目表未能读取。需确认该个人账号实际可选的类目及其适用范围 |
| API 合法域名配置入口 | PASS | 腾讯云官方小程序 COS 文档要求在微信公众平台的服务器域名中分别配置 request / uploadFile 域名 [6]；仅核实该配置要求和入口，未证明当前 SoloOps 域名获准 |
| HTTPS / 域名完整准入细则 | BLOCKED | 官方网络页在检索工具中不可读取，浏览器工具又被站点安全策略阻止；未绕过限制。需在发布前读当前官方规范并以账号后台复核 [5] |
| 真实域名、证书和 TLS 联通 | NOT_TESTED | 尚无部署地址；构建配置保留 `urlCheck: true`。正式实现应使用有效 HTTPS，并分别核对 request / uploadFile / downloadFile / socket 的允许域名、端口和重定向要求 |
| 发布附加条件 | NOT_TESTED | 主体认证、服务类目资质、备案状态、隐私保护指引、权限说明、版本审核、测试账号与联系方式都需按最终功能及账号后台确定；当前编译结果不能证明可发布 |

## 三类主体的适用性

| 主体 | 当前判断 | 需要账号后台或运营方确认 |
|---|---|---|
| 个人 | NOT_TESTED | 本项目当前主体（用户确认）；此状态指类目/发布适用性尚未核验。对实际“卖家经营管理”功能可选的类目及其允许范围；是否涉及个人主体受限服务、收费、AI内容能力。既不能断言一定可发布，也不能断言一定不可发布 |
| 个体工商户 | NOT_TESTED | 平台当前主体类型归类、营业执照核验、经营范围、类目专项材料与认证要求 |
| 企业 | NOT_TESTED | 企业主体核验及所选类目资质；企业身份本身不等于所有经营/AI类目获准 |

可向平台说明的功能材料是“卖家经营资料和经营效率管理”。“工具/效率”“商业服务/企业管理”仅为咨询时的搜索方向，当前准确名称、代码、准入主体和材料未核实。若未来加入交易、支付、公开 AI 生成内容或其他服务，须按新增功能重新核对；本次不提前扩展范围。

## 后续可执行核对

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) 的对应小程序账号，进入“设置 > 基本设置 > 服务类目”查看现有类目；如未设置，查看“添加类目”中的可选项和说明，记录与卖家经营管理功能相符的候选及材料要求。后台尚未核实前不指定最终类目；保留日期与官方页面证据，避免提交身份证件到仓库。
2. 根据真实部署区域向接入商确认网站/API 域名 ICP 要求；单独核对微信小程序备案和合法域名配置，不能互相替代。
3. 提供合成资料测试域名，逐类验证 HTTPS 证书链、域名白名单、上传/下载和错误状态。M0-A 未执行网络业务测试。
4. 正式发布前再核对当前隐私、AI服务及内容审核规则是否适用。需账户操作和材料审核的事项由下一次授权安排。

## W02：文件导入（2026-10-11）

- `pages/imports`：五种报表、渠道/身份/时区/导出时间、CSV/XLSX选择、模板分享、映射及个人模板/候选、预览、逐行纠错、旧新值、语义审阅、版本提交与回读、最近100批、撤销/清除及错误CSV分享。

- 后端新增 `/shops/{shop_id}/imports/multipart`；封套先限长再解析，仅接受一个file，复用原ImportService，身份/店铺/版本/来源校验沿用原逻辑。`python-multipart` 已锁定。
- 上传/下载共用ApiClient认证和generation保护；不重放写入。采用@noble/hashes 1.8.0，其MIT许可证已收录。

# SoloOps 马卡龙界面设计与验收

日期：2026-10-14。面向独立跨境电商卖家的文件分析与运营工作台。

## 视觉方向与诊断

采用暖白背景、鼠尾草绿主操作、杏桃／奶油黄／浅紫辅助色。浅色导航降低长时间使用的视觉负担，彩色表面用于区分工作状态与常用任务；正文始终使用深色，状态同时提供文字，颜色不承担唯一含义。

| 原有问题 | 实施结果 |
| --- | --- |
| 深蓝侧栏与亮蓝渐变占据主视觉 | 浅鼠尾草侧栏、暖白画布、单一绿色主要操作，辅助色集中到任务区 |
| 导航、说明与表单标签常为 10–12px | 正文 14px、辅助 12px、标签 13px；手机输入 16px |
| 筛选先于任务状态，卡片层级接近 | 首页先呈现常用入口和真实任务计数，再呈现范围筛选及单列工作记录 |
| 手机导航占用约 347px | 默认折叠菜单，品牌区约 90px；19 个功能入口仍可展开访问 |
| 日期及嵌套内容在平板拥挤 | 日期字段在 960px 以下跨完整行；表格在自身容器滚动 |

## 可复用规则

全部基础变量位于 `frontend/src/styles/tokens.css`，全页组件规则位于 `frontend/src/styles/soloops.css`。

| 角色 | Token／值 | 用途 |
| --- | --- | --- |
| 页面 | `--canvas: #f7f8f5` | 暖白工作区 |
| 表面 | `--surface: #ffffff` | 表单、记录、主要内容 |
| 次级表面 | `--surface-soft: #f2f5ef` | 来源说明、历史与辅助证据 |
| 导航 | `--sidebar: #f0f4ed` | 持续可见的功能导航 |
| 正文／次要文字 | `--ink: #293b34`／`--muted: #68766f` | 标题、业务内容／帮助说明 |
| 边框 | `--line: #dfe5dd`／`--line-strong: #bdcbbf` | 区块／交互控件 |
| 主要操作 | `--accent: #426856`／hover `#345442` | 导入、保存、确认；键盘焦点 |
| 杏桃 | `--peach: #f8e4d8` | 待处理与工作流程 |
| 奶油黄 | `--butter: #f7eed2` | 更新数据、待核对及引导 |
| 浅紫 | `--lilac: #eae5f3` | 数据入口与账户 |
| 成功／警告／错误 | `#35624b`／`#805c24`／`#a43d42` | 配套浅色底面与明确状态文字 |

- 字体：Segoe UI、PingFang SC、Microsoft YaHei、Noto Sans CJK SC；品牌采用 Trebuchet MS。使用本地字体栈，中文保持清晰；正文行高 1.7，标题 1.4，数字采用等宽数字。
- 字阶：标题 24–32px、区块 20px、内容标题 16px、正文 14px、表单标签 13px、辅助 12px；手机标题 25px、区块 18px。
- 布局：内容最大 1440px、12 列栅格；侧栏 236px，中等屏幕 220px；页面内边距 32px，手机 16px。760px 以下收起导航，多列表单变为单列。
- 间距：4、8、12、16、20、24、32、40、48px；区块间距 24px、内容区内边距 24px。
- 组件：主要控件 44px、手机输入 46px；小按钮 38px，手机按钮 44px；控件圆角 10px、内容区 18px。轻阴影用于区分表面；交互采用明确边框和克制的 hover／active 反馈。
- 图标：本地 `AppIcon.vue`，统一 24×24 viewBox、1.7px 线宽；常规显示 20px，仅辅助图标隐藏于辅助技术。
- 状态：保留 loading、disabled、error、retry 与原确认门禁；任务视图以文字和选中边框区分；空态给出下一步入口。
- 动效：160ms 的颜色、边框和阴影过渡；遵循 `prefers-reduced-motion`。
- 手机菜单：支持按钮切换、Escape、导航成功和重复导航后的收起及焦点恢复；被守卫取消的导航保持菜单展开。

## 实施文件与功能连续性

- `styles/tokens.css`、`styles/soloops.css`：统一 20 个页面的主题、布局、控件与响应式。
- `components/AppShell.vue`、`SellerNavigation.vue`、`AppIcon.vue`：浅色壳层、当前页面面包屑、统一图标及手机菜单。
- `views/DashboardView.vue`、`components/WorkInbox.vue`：常用入口、任务状态优先、记录列表；快捷入口复用收件箱当前店铺／身份／渠道。
- `views/LoginView.vue`：统一登录表面与三步工作流程说明。
- `views/ImportsView.vue`：导入流程引导、上传区与表单阅读层级。
- `__tests__/AppShell.spec.ts`、`__tests__/WorkInbox.spec.ts`：菜单焦点和导航失败语义、范围向父级同步的回归检查。

API、身份认证接口、19 个业务路由、关键审批／导入／来源／时间范围流程继续使用既有实现。工作视图仍为“待我处理、AI 已完成、需要更新数据”，计数取自服务端。

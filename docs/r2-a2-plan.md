# R2 A2 最小差异计划

日期：2026-10-10。授权依据见 `r2-progress.md`；实施以前包 A1-3 代码 `5b420abf67ab7a4ba7faf928773876e1f7f21ce3` 的目标 CI 成功为前置。

## 实现范围

1. 保留 `profit_calculation.py` 的订单状态、数量、折扣、退款、Decimal 和分币种规则。分析增加成本模式，默认当前采购成本回推估算；卖家历史成本模式只使用该订单源行的有效人工凭据，缺失或异币种保持未知。新结果标计算版本，旧快照保留公式和数值。
2. 新增订单成本版本表及 Model / Repository / Service；API 置于已有经营分析路径。记录单位成本、币种、凭据说明、带时区的凭据时间、卖家确认及创建时间，绑定当前订单源行。按源行追加版本和撤销事件，用请求 UUID、预期版本和店铺数据版本防止重复及并发覆盖，不改导入原值。
3. 成本变化递增店铺数据版本并复用失效链。订单来源覆盖或撤销使凭据待重核；恢复旧订单源行也不自动恢复已失效确认。清除订单批次时擦除凭据内容及相关历史报告，保留无内容审计。商品现成本变化不改写历史凭据。
4. `AnalyticsView` 增加模式选择；订单证据区提供录入、修订、撤销和版本回读。显示净销售额、所选成本商品毛利、费用缺失及净利润未知；总览和既有运营计算继续明确显示当前成本估算。保留既有路由和样式。
5. 人工费用与平台账单继续通过已有凭据核对、重复/异币种/未分摊门禁处理。本包商品毛利不自动扣这些金额，界面链接到已有费用/账单入口；验证重复费用不会被再次扣减，不将已知毛利改名为净利润。

# SoloOps 三端工程

本目录只包含 M0-A 最小启动工程。

| 端 | 工程目录 | 页面源码 |
|---|---|---|
| Android | `soloops_flutter/android/` | `soloops_flutter/lib/` |
| 鸿蒙 NEXT / OHOS | `soloops_flutter/ohos/` | 同一份 `soloops_flutter/lib/` |
| 微信小程序 | `soloops_weapp/` | `soloops_weapp/src/` |

后端仍为仓库 `backend/`，原 Web 仍为 `frontend/`。业务映射见
[`UI 契约`](../docs/mobile/ui-contract.md)，实际验收见
[`M0-A 报告`](../docs/mobile/m0a-report.md)。
